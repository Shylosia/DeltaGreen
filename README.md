# 绿色三角洲自动人物卡

在 Excel 工作簿内完成人物创建、职业技能分配、幕间结算、规则查询与两页 A4 人物卡打印。

**当前版本：v2.0**

- [查看更新记录](./CHANGELOG.md)
- [绿箱生成器](https://greenbox.thebackstop.app/)

仓库提供空白母版及使用、更新说明；已填写的角色版保留在本地。下载后先另存为自己的角色文件，再填写资料。

## 开始使用

| 操作 | 位置与说明 |
| --- | --- |
| 填写初始属性 | 在主人物卡第一列填写原始属性；相邻现值列显示计入背景和已归档变化后的结果。建卡无需先填幕间。 |
| 选择职业 | 在人物卡的职业框选择职业及适用子模板，固定技能自动进入技能表。 |
| 确认职业任选技能 | 选中候选左侧状态格，点下拉箭头选择 ☑／☐，或按 Alt＋↓ 打开列表。空候选自动隐藏，不参与计分。 |
| 填写技能细项 | 外语、工艺、科学等细项可直接在主卡对应名称格填写。职业固定工艺按专攻名称匹配，放到其他工艺行后仍可计入；同名只计一次。 |
| 分配额外技能 | 选择技能包后载入八项分配。模板固定项也可在右栏换选技能；清空手选后恢复默认项。 |
| 核对技能包 | 每项 +20，可重复选择同一技能，创建上限为 80，不能提升非自然知识。分配统计在第八项下方。 |
| 选择创伤背景 | 在创伤背景框选择背景并确认待选内容，固定效果自动计入对应属性、技能和状态。 |
| 选择装备 | 物品栏顶部默认“跟随职业”，也可改选五组装备包。武器名称另行下拉选择，带入技能及武器数值；护甲和特训有对应选项。 |
| 记录理智与关系 | 在“理智与关系记录”选择事项，填实际损失、投射／抑制骰点和关系目标，核对后归档。 |
| 记录幕间事项 | 在单一幕间计算区选择活动，按显示字段填写；每次使用独立记录号，归档后计入主卡。 |
| 结算技能失败 | 在主卡技能左侧下拉选择 √；幕间页自动列出勾选技能和当前值，填各项1D4后，整批粘贴为值到归档区。 |
| 查阅规则 | 规则速查、精神疾病、参考选项均为工作表，可复制文字；编辑固定内容前先取消工作表保护。 |
| 记录模组经历 | 模组经历备忘录预留20场，可记录场次、经历和后续事项。 |
| 打印人物卡 | 使用“可打印版（A4）”工作表，按两页 A4 打印。 |

切换职业、技能包或背景后，核对之前保留的手选内容。新增技能细项时，先在主卡填写名称，再到对应选择格选取。

## 模组结束与幕间

1. 在经历表按序号填写模组名称。“幕间与结算”选择相同模组编号，名称自动带入；未填写名称时留空。
2. 游戏中在主卡勾选失败技能。模组结束后，通过“技能成长”入口查看自动清单，填各项实掷1D4。点击“选取本次成长记录”复制，再点击“前往归档空行”，使用“选择性粘贴 → 值”（Ctrl+Alt+V，再按 V、Enter）。
3. 清空主卡失败标记与本次骰点。回到上方幕间计算区，填写记录号、选择事项；窗口按事项显示所需字段、下拉选项及骰点提示。不使用的字段不参与计算。
4. 状态为“可归档”后，点击“选取本次幕间记录”复制，再点击“前往归档空行”，粘贴为值。清空本次输入，换用提示的下一笔记录号，即可重复计算，不限于两次。

归档只粘贴前九列 A:I，右侧两列保留公式。生成的幕间记录连续排列，没有夹在中间的空行。归档区是 Excel 表格。归档 A:I 可填写或更正；删除整行等结构操作需先取消工作表保护。更正已有记录会重新计算对应变化。

“选取本次输入”只选择可填区域，按 Delete 清空即可；记录号与模组编号保留。下一模组更换模组编号，幕间记录号可重新从1开始。已经使用过的记录号显示旧记录，再次归档不会重复计分。

自动清单是实时预览，**粘贴为值才会固定历史并计入主卡**。技能失败成长同一模组同一技能只计一次，上限99；0%的技能和非自然知识不参与失败1D4。专攻按完整技能名保存，移动行位仍可匹配。

疾病痊愈、特训名称、人生动力等文字变化写入事件，并在主卡相应文字栏更新。新关系名称先填入主卡，再选择对应关系编号。幕间次数及具体活动安排由游戏中的实际情况决定。

物品栏默认“跟随职业”，也可以单独选择装备包。可选与二选一装备仍需玩家确认。切换装备包不会替换已选武器行；如需手工覆盖自动物品公式，先取消工作表保护并自行保留原公式备份。

## 游戏内事件

在“理智与关系记录”选择事项，填写实际骰点与事件经过。窗口显示适用字段，支持投射、抑制、关系受损／破碎、DG 关系、恢复和适应代价。

核对显示“可归档”后，点击“选取本次事件记录”，复制 A:I 并粘贴为值到归档空行。确认记录后，主卡的理智、毅力、关系、崩溃点与适应进度随归档累计；清空窗口不会撤销已归档变化。每次理智检定单独记录，重复编号不会重复计入。

详细历史见[更新记录](./CHANGELOG.md)。

## 查询与备忘

规则速查顶部提供12个主题入口。若跳转后看不到目标内容，先清除筛选，再点击目录；也可查找关键词。

精神疾病和参考选项集中提供常用选择；模组经历备忘录用于记录行动及后续事项，幕间与结算用于累计确认后的角色变化。主卡、规则速查和备忘录均设有绿箱生成器入口。
