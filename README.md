# 绿色三角洲自动人物卡

在 Excel 工作簿内完成人物创建、职业技能分配、装备选择、规则查询与两页 A4 人物卡打印。

**当前版本：v1.8**

- [下载 v1.8 空白母版](<./A绿色三角洲-自动人物卡 v1.8_空白母版.xlsx>)
- [查看更新记录](./CHANGELOG.md)
- [绿箱生成器](https://greenbox.thebackstop.app/)

仓库提供空白母版及使用、更新说明；已填写的角色版保留在本地。下载后先另存为自己的角色文件，再填写资料。

## 开始使用

| 操作 | 位置与说明 |
| --- | --- |
| 选择职业 | 在人物卡的职业框选择职业及适用子模板，固定技能自动进入技能表。 |
| 确认职业任选技能 | 选中候选左侧状态格，点下拉箭头选择 ☑／☐，或按 Alt＋↓ 打开列表。空候选自动隐藏，不参与计分。 |
| 填写技能细项 | 外语、工艺、科学等细项可直接在主卡对应名称格填写。职业固定工艺按专攻名称匹配，放到其他工艺行后仍可计入；同名只计一次。 |
| 分配额外技能 | 选择技能包后载入八项分配。模板固定项也可在右栏换选技能；清空手选后恢复默认项。 |
| 核对技能包 | 每项 +20，可重复选择同一技能，创建上限为 80，不能提升非自然知识。分配统计在第八项下方。 |
| 选择创伤背景 | 在创伤背景框选择背景并确认待选内容，固定效果自动计入对应属性、技能和状态。 |
| 填写意志与魅力 | 在创伤背景框填写原始意志和原始魅力，上方显示修正后的属性。 |
| 选择装备 | 武器名称栏可下拉选择，自动带入技能及武器数值；护甲和特训也有对应选项。 |
| 查阅规则 | 规则速查、精神疾病、参考选项均为工作表，可复制和编辑文字。 |
| 记录模组经历 | 模组经历备忘录预留20场，可记录场次、经历和后续事项。 |
| 打印人物卡 | 使用最后的可打印版（A4）工作表，按两页 A4 打印。 |

切换职业、技能包或背景后，核对之前保留的手选内容。新增技能细项时，先在主卡填写名称，再到对应选择格选取。

游戏中的当前状态、成长及自定义内容按实际经历维护。手动改写公式会替换该格的自动计算，建议保留一份空白母版。

## v1.8 本次变化

- 修正固定工艺的名称匹配，调整工艺所在行后仍能获得职业值；原位置优先，同名只计一次。
- 核对计算机科学家或工程师的电工30%、机械30%、微电子40%，以及相关职业固定工艺。
- 四个工艺名称栏的下拉补入“电子学”；保留原有“电子”和“微电子”，分别按名称填写。
- 保留原有版式、职业任选、技能包逐项替换及额外技能联动。

详细历史见[更新记录](./CHANGELOG.md)。

## 查询与备忘

规则速查顶部提供12个主题入口。若跳转后看不到目标内容，先清除筛选，再点击目录；也可查找关键词。

精神疾病和参考选项集中提供常用选择；模组经历备忘录用于记录行动及后续事项。主卡、规则速查和备忘录均设有绿箱生成器入口。
