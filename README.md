# 绿色三角洲自动人物卡

在 Excel 工作簿内完成人物创建、职业技能分配、装备选择、规则查询与两页 A4 人物卡打印。

**当前版本：v1.6**

- [下载 v1.6 空白母版](<./A绿色三角洲-自动人物卡 v1.6_空白母版.xlsx>)
- [查看更新说明](./CHANGELOG.md)
- [绿箱生成器](https://greenbox.thebackstop.app/)

仓库提供空白母版及使用、更新说明；已填写的角色版仅保留在本地。下载后先另存为自己的角色文件，再填写资料。

## 开始使用

| 操作 | 位置与说明 |
| --- | --- |
| 选择职业 | 在“人物卡”的职业框选择职业及适用的子模板。固定技能自动带入上方技能表。 |
| 确认职业任选技能 | 选中候选左侧的状态格，点下拉箭头选择 ☑／☐。也可按 Alt＋↓ 打开列表。空候选自动隐藏，不参与计分。 |
| 填写技能细项 | 外语、工艺、科学等细项可直接在主卡对应名称格填写。 |
| 分配额外技能 | 在额外技能框选择技能包并确认待选细项。自选的八次分配各为 20 点，可重复分配，创建上限为 80。 |
| 选择创伤背景 | 在创伤背景框选择背景并确认待选内容。固定效果自动计入对应属性、技能和状态。 |
| 填写意志与魅力 | 在创伤背景框填写“原始意志”和“原始魅力”，上方显示修正后的属性。 |
| 选择武器 | 在武器名称栏选择武器，自动带入对应技能与武器数值；护甲和特训也有相应下拉选项。 |
| 查阅规则 | 打开“规则速查”“精神疾病”或“参考选项”工作表；说明直接保存在单元格中，可复制、编辑。 |
| 记录模组经历 | 在“模组经历备忘录”工作表填写场次、经历和后续事项，预留 20 场。 |
| 打印人物卡 | 使用最后的“可打印版（A4）”工作表，自动引用主卡数据，按两页 A4 打印。 |

切换职业、技能包或背景后，核对之前保留的手选内容。要添加新的技能细项，可先在主卡填写名称，再到对应选择格选取。

游戏过程中的当前状态、成长及自定义内容，按实际经历维护。直接覆盖公式会改变该格之后的自动联动，建议保留一份空白母版。

## 工作簿内的查询与备忘

“规则速查”顶部提供 12 个分类入口，点击后跳到对应正文。若跳转后仍看不到目标内容，先清除该表的筛选条件，再点击目录；也可使用 Excel 查找定位关键词。v1.6 将冻结范围从前 25 行缩小为前 8 行，避免顶部大片目录遮挡正文。

“精神疾病”集中列出疾病说明及相关细项，“参考选项”集中放置创建和游戏中需要选择的内容。“模组经历备忘录”用于长期记录角色参加过的模组与待办事项。绿箱生成器入口同时放在主卡底部、规则速查及备忘录中，便于备团和游戏时使用。

- 修正规则速查跳转体验，精简为 12 个入口，并补充清除筛选提示。

- 打印页 135 处数值或基础等级标签在对应基础值为空时以 0 占位；姓名、专攻名称、经历等文字栏仍保留空白。
- 同步主卡、打印页、文档属性及更新记录中的版本信息。
- 保留职业候选框的下拉勾选与空项自动隐藏，清理重复提示、填写位置和备注中的页码。
- 更新记录按最新版本到 v0.1.0 排列。
