# 绿色三角洲自动人物卡

在 Excel 工作簿内完成人物创建、职业技能分配、幕间结算、规则查询与两页 A4 人物卡打印。

**当前版本：v1.10**

仓库提供空白母版及使用、更新说明；已填写的角色版保留在本地。下载后先另存为自己的角色文件，再填写资料。

## 开始使用

| 操作 | 位置与说明 |
| --- | --- |
| 填写初始属性 | 在“幕间与结算”的初始属性栏填写，主卡显示计入背景与后续变化后的累计值。 |
| 选择职业 | 在人物卡的职业框选择职业及适用子模板，固定技能自动进入技能表。 |
| 确认职业任选技能 | 选中候选左侧状态格，点下拉箭头选择 ☑／☐，或按 Alt＋↓ 打开列表。空候选自动隐藏，不参与计分。 |
| 填写技能细项 | 外语、工艺、科学等细项可直接在主卡对应名称格填写。职业固定工艺按专攻名称匹配，放到其他工艺行后仍可计入；同名只计一次。 |
| 分配额外技能 | 选择技能包后载入八项分配。模板固定项也可在右栏换选技能；清空手选后恢复默认项。 |
| 核对技能包 | 每项 +20，可重复选择同一技能，创建上限为 80，不能提升非自然知识。分配统计在第八项下方。 |
| 选择创伤背景 | 在创伤背景框选择背景并确认待选内容，固定效果自动计入对应属性、技能和状态。 |
| 选择装备 | 物品栏顶部默认“跟随职业”，也可改选五组装备包。武器名称另行下拉选择，带入技能及武器数值；护甲和特训有对应选项。 |
| 记录幕间事项 | 技能成长归档后，使用第1次／第2次幕间面板，选择活动、结果、目标及必要骰点；自动生成变化记录，归档后计入主卡。 |
| 结算技能失败 | 在主卡技能左侧下拉选择 √；幕间页自动列出勾选技能和当前值，填各项1D4后，整批粘贴为值到归档区。 |
| 查阅规则 | 规则速查、精神疾病、参考选项均为工作表，可复制和编辑文字。 |
| 记录模组经历 | 模组经历备忘录预留20场，可记录场次、经历和后续事项。 |
| 打印人物卡 | 使用“可打印版（A4）”工作表，按两页 A4 打印。 |

切换职业、技能包或背景后，核对之前保留的手选内容。新增技能细项时，先在主卡填写名称，再到对应选择格选取。

## 模组结束与幕间

1. 游戏中直接在主卡勾选失败技能。模组结束后，到“幕间与结算”选择模组编号、填写游戏内日期；上方自动生成结算清单。
2. 先完成全部勾选，再为清单的每项填写实际掷出的1D4。清单状态变为“可归档”后，复制有内容行的前九列 A:I，在归档区的第一条空行使用“选择性粘贴 → 值”（Ctrl+Alt+V，再按 V、Enter）。技能成长随即计入主卡。
3. 清空主卡失败标记和本次骰点。随后进行第1次幕间：选择事项、结果、目标、骰点及需要承担代价的关系，填写游戏内事件；将下方生成记录的前九列同样粘贴为值到归档空行。需要第二次幕间时，按相同步骤继续。
4. 下一模组更换编号，清空两组幕间输入后重新选择。归档记录保留，旧成长继续累计。

可以在 Excel 公式栏左边的名称框选取 `本次成长记录`、`幕间一记录`、`幕间二记录`，直接复制对应范围；选取 `失败标记` 或 `本次骰点` 后按 Delete 可清空对应输入。归档区只粘贴前九列，保留右侧的计算列。

自动清单是实时预览；**粘贴为值才会固定历史并计入主卡**。同一模组同一技能的重复记录不再计分。成长上限99，0%的技能和非自然知识不参与失败1D4。专攻按完整技能名保存，移动行位仍可匹配。

两次幕间按先后归档。活动中的数值变化会自动列出；疾病痊愈、特训名称、人生动力等文字变化写入事件，并在主卡相应文字栏更新。新关系的名称先填入主卡，再在幕间选择对应关系编号。

物品栏的“跟随职业”会使用职业所列装备，已有对应清单时展开为物品。可选与二选一装备仍需玩家确认。切换装备包不会替换已选武器行；要自行填写物品，可选“自定义”后在物品格内输入，输入会替换该格公式。

## 查询与备忘

规则速查顶部提供12个主题入口。若跳转后看不到目标内容，先清除筛选，再点击目录；也可查找关键词。

精神疾病和参考选项集中提供常用选择；模组经历备忘录用于记录行动及后续事项，幕间与结算用于累计确认后的角色变化。主卡、规则速查和备忘录均设有绿箱生成器入口。
